# Infinite Minesweeper

A standalone, installable Infinite Minesweeper PWA.

## GitHub Pages
1. Create a new GitHub repository.
2. Upload **all four files**: `index.html`, `manifest.json`, `sw.js`, `icon.svg`.
3. In GitHub: Settings → Pages → Deploy from branch → `main` / root.
4. Open the generated Pages URL on your iPad.
5. In Safari, use **Share → Add to Home Screen**.

Progress is saved in the browser on that device.

## Controls
- Tap a cell to reveal.
- Right-click or long-press to flag.
- Drag empty space to pan.
- Pinch/scroll or +/- to zoom.
- 🗺️ shows explored progress.
- 🌙 toggles dark mode.
